# ল্যান্ডলক ইঞ্জিন (LandLock Engine)
### Automated Injunction & Title Encumbrance Registry
> **স্লোগান:** নিরাপদ জমি। স্বচ্ছ মালিকানা। একটি ন্যায্য বাংলাদেশ।  
> **প্রকল্পের ধরণ:** ই-গভর্ন্যান্স / গভটেক / লিগ্যালটেক (বাংলাদেশ)

---

## 📌 ওভারভিউ (Overview)
ল্যান্ডলক ইঞ্জিন হলো আদালত, ভূমি প্রশাসন (এসিল্যান্ড), সাব-রেজিস্ট্রি এবং ব্যাংকসমূহের মধ্যে একটি কেন্দ্রীয় সমন্বিত যাচাই প্ল্যাটফর্ম। জমি হস্তান্তরের পূর্বে জমিতে কোনো বৈধ আদালতের নিষেধাজ্ঞা, বিরোধ বা অপরিশোধিত বন্ধক রয়েছে কিনা তা তাৎক্ষণিকভাবে যাচাই করে জালিয়াতি রোধ করা এই প্ল্যাটফর্মের মূল লক্ষ্য।

---

## 🚀 এক ক্লিকে সম্পূর্ণ প্রজেক্ট চালু করার উপায় (How to Run)

এই প্রজেক্টে যেকোনো অপারেটিং সিস্টেমে (macOS, Windows, Linux) একক কমান্ডে সবকিছু চালু করার জন্য সার্বজনীন স্ক্রিপ্ট যুক্ত করা হয়েছে:

### অপশন ১: ইউনিভার্সাল রানার (সব OS-এর জন্য সবচেয়ে সহজ)
যেকোনো অপারেটিং সিস্টেমে টার্মিনালে প্রজেক্টের রুট ডিরেক্টরিতে চালান:
```bash
npm start
```
*(এটি স্বয়ংক্রিয়ভাবে আপনার ওএস ডিটেক্ট করে সঠিক স্ক্রিপ্টটি চালু করবে)*

---

### অপশন ২: ম্যাক বা লিনাক্স (macOS / Linux)
টার্মিনালে সরাসরি স্ক্রিপ্টটি চালান:
```bash
./start.sh
```

---

### অপশন ৩: উইন্ডোজ (Windows)
কমান্ড প্রম্পট (cmd) বা ফাইল এক্সপ্লোরার থেকে ডাবল-ক্লিক করে চালান:
```cmd
start.bat
```

---

### অপশন ৪: ডকার কম্পোজ (কোনো লোকাল টুল ছাড়াই যেকোনো OS-এ)
আপনার মেশিনে শুধুমাত্র ডকার থাকলেই চলবে (Java বা Node.js প্রয়োজন নেই):
```bash
docker compose up --build
```

## 🌐 সার্ভিসসমূহের লিংক (URLs)

চালু হওয়ার পর নিচের লিংকগুলোতে প্রবেশ করতে পারবেন:

| সার্ভিস | ইউআরএল (URL) | বিবরণ |
|---|---|---|
| **ওয়েব পোর্টাল (Frontend)** | [http://localhost:5173](http://localhost:5173) | নাগরিক ও প্রাতিষ্ঠানিক বাংলা ওয়েব পোর্টাল |
| **এপিআই ব্যাকএন্ড (API)** | [http://localhost:8080](http://localhost:8080) | স্প্রিং বুট REST API |
| **সোয়াগার ডকুমেন্টেশন** | [http://localhost:8080/swagger-ui.html](http://localhost:8080/swagger-ui.html) | ইন্টারঅ্যাক্টিভ API টেস্টিং |
| **ডাটাবেজ (PostgreSQL)** | `localhost:5433` (DB: `landlockdb`) | ডকার কন্টেইনার |

## 🔑 পরীক্ষামূলক ডেমো অ্যাকাউন্টসমূহ (Demo Logins)

| `order_approver1` | আদেশ অনুমোদনকারী (ORDER_APPROVER) | বিচারিক আদেশ অনুমোদন ও প্রত্যাহার |
| `registry_officer1` | রেজিস্ট্রি কর্মকর্তা (REGISTRY_OFFICER) | দলিল রেজিস্ট্রির পূর্বে জমিতে লেনদেন যাচাই |
| `bank_officer1` | ব্যাংক কর্মকর্তা (BANK_OFFICER) | ঋণের বিপরীতে বন্ধকী লিয়েন নথিবদ্ধ ও ছাড় |
| `citizen1` | নাগরিক (CITIZEN) | সাধারণ নাগরিক ভিউ |
| `auditor1` | অডিটর (AUDITOR) | নিরীক্ষা লগ ও অডিট ট্রেইল পরিদর্শন |
| `admin1` | সিস্টেম প্রশাসক (SYSTEM_ADMIN) | সম্পূর্ণ সিস্টেম কনফিগারেশন |

## 🏗️ টেকনোলজি স্ট্যাক (Tech Stack)
- **ব্যাকএন্ড:** Java 21, Spring Boot 3.3.4, Spring Security 6 (Stateless JWT), Spring Data JPA, Flyway DB Migrations
- **ফ্রন্টএন্ড:** React 18, Vite, Tailwind CSS, TanStack Query, React Hook Form, Lucide Icons (বাংলাদেশ সরকারি থিম)
- **ডাটাবেজ ও ডেভপস:** PostgreSQL 15, Docker & Docker Compose
